Simple setup

Up and running in 3 steps

01

Create your account

Register with your name and email. Your session is secured with server-side authentication — no third-party sign-in required.

02

Start Ollama locally

Run ollama serve and pull a model like ollama pull llama2. MaaSathi connects automatically — no API keys needed.

03

Chat, plan & get organised

Use the dashboard to chat, add tasks, plan meals, set reminders, and trigger SOS — all powered by your local AI.
